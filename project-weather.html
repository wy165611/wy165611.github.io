极致气象体验

遵循 Apple HIG 规范，由 React 强力驱动的一抹纯净天空。

React Tailwind CSS OpenWeather API

01. The Challenge

简化复杂数据

市面上的天气应用大多堆砌了繁杂的气象数据，用户难以第一时间捕获核心信息。本项目的使命是“做减法”：通过极简的空间留白与直观的图形状态，摒弃一切不必要的信息噪音。

02. Solutions

视觉与交互设计

在界面渲染上，借助 Tailwind CSS 封装了多种依赖真实时间戳与天气代码的 UI 渐变背景（清晨、黄昏、雨夜等）。

通过 Lottie 集成了微动效（如浮云飘动、雨滴下落），极大地提升了情感化设计维度。由于使用纯函数式组件封装状态逻辑，代码量减少了近一倍，启动速度极快。
