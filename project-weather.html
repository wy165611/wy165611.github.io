温柔气象体验.

剥离一切无效数据，只留下带有微光色彩的动态天气语言。

React Tailwind CSS Framer Motion Weather API

01 / Challenge

当外面的天气糟糕时，看天气预报往往让人心情沉重。大部分天气软件充满了冷灰的云图和警告标识。

我们需要一款做“减法”并且具备“温度”的天气 App。去除干扰噪音，用轻量的设计给使用者提供正向的情绪价值。

02 / Solutions

在界面渲染上，借助 Tailwind 封装了一整套治愈系的软渐变。即便是阴雨天，我们也能用柔和的水粉蓝色来呈现，而不是吓人的黑灰色。

通过 Framer Motion 将微动效注入太阳的升起和云层的漂移，赋予无生命的数据以温度与自然律动感。
