一套高度可复用，基于 TypeScript 构建的企业级组件库体系。

TypeScript Unocss Monorepo Vitest

01. The Challenge

团队协作壁垒

随着业务线扩张，多个前端应用之间的 UI 呈现和交互逻辑存在严重的不一致。由于缺乏统一的代码资产与规范约束，重复造轮子导致了开发和测试成本居高不下。

02. Solutions

原子化样式与类型安全

采用原子化 CSS 引擎（Unocss）剥离样式层，确保组件本身只有纯粹的状态和 DOM 结构。结合 TypeScript 提供完备的声明与类型推断，使得在使用组件时拥有完美的 IDE 补全体验。

通过 pnpm 的 workspace 功能实现 Monorepo 的多包管理架构，核心交互层、样式预设层和文档展板实现了解耦复用。

03. Outcomes

标准化与基石

  • 累计产出 40+ 基础与中台复合组件，编写测试用例覆盖率达 95%。
  • 新项目的脚手架搭建及基础 UI 并入时间缩短了 70%。
  • 作为设计规范落地的技术承载体，彻底打破了设计部门与前端的协作壁垒。
